# ATS DOCX Resume

Use a **single-column, reverse-chronological, text-first resume** with standard headings, clear fields, and evidence-rich bullets.

## Section Order

1. Contact Information
2. Professional Summary
3. Core Skills
4. Professional Experience
5. Education

## Writing Rules

- Keep contact details in the main document body.
- Use full, labeled LinkedIn and portfolio URLs.
- Keep the summary to **2–4 concise lines**.
- Group skills with plain-text labels and use standard terminology.
- Repeat important skills naturally in relevant experience bullets.
- Make each role a self-contained record: **Title → Employer → Location → Dates → Bullets**.
- Use **3–6 high-value bullets** for recent roles; fewer for older roles.
- Prefer: **Action + context + skill/method + result**.
- Quantify outcomes with metrics whenever possible.
- Use consistent dates such as `July 2024 – Present`.

## Format Rules

- DOCX by default.
- One column; top-to-bottom reading order.
- Strictly 1 page.
- Use standard font Arial at 10 pt size.
- Avoid tables, columns, sidebars, text boxes, icons, skill bars, timelines, hidden keywords, and image-only PDFs.
- Use conventional headings such as `Professional Summary`, `Core Skills`, `Professional Experience`, and `Education`.
